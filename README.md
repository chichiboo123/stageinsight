# 여기 있어 공연장 (Stage Insight)

> 학교와 예술을 연결하다 — 교사를 위한 공연 연계 교육과정 탐색 도구

**개발자:** [교육뮤지컬 꿈꾸는 치수쌤](https://litt.ly/chichiboo)

---

## 소개

**여기 있어 공연장 _ Stage Insight**는 학교 교사가 주변 공연장의 공연 정보를 탐색하고, 이를 교육과정 성취기준과 연계하여 수업을 설계할 수 있도록 돕는 웹 서비스입니다.

공연 관람을 단순한 문화 체험이 아닌, 교육과정과 맞닿은 수업 활동으로 연결하고자 하는 교육 현장의 고민에서 출발했습니다.

---

## 사용법

| 단계 | 내용 |
|------|------|
| 1. 학교 검색 | 홈 화면에서 학교 이름을 검색하세요. 유치원·초·중·고 모두 지원합니다. |
| 2. 공연장 선택 | 학교 선택 시 주변 공연장이 홈 화면에 바로 표시됩니다. 공연장 카드를 클릭하세요. |
| 3. 공연 선택 | 공연 대시보드에서 현재 공연 목록을 확인하고 원하는 공연을 선택하세요. |
| 4. 교육과정 연계 | 공연 선택 시 성취기준·연계 영화·도서가 자동으로 표시됩니다. 학년군·교과 필터로 좁힐 수 있고, ✨ 버튼으로 AI 작품 소개·큐레이션을 받을 수 있습니다. |
| 5. 인사이트 바구니 담기 | 북마크(🔖) 버튼으로 공연·성취기준·영화·도서를 인사이트 바구니에 담으세요. |
| 6. AI 융합수업 설계 | 바구니의 공연 그룹에서 "✨ AI 융합수업 설계"를 누르면 작품 줄거리부터 학습목표·활동·발문까지 수업 초안을 만들어 메모로 저장합니다. (KOPIS에 줄거리가 없어도 AI가 작품 줄거리를 보완합니다.) |
| 7. 메모 · 내보내기 | 공연별 메모를 작성하고, 이미지·PDF 저장, 클립보드 복사, URL 공유, 💾 JSON 저장/불러오기로 정리할 수 있습니다. |

## 주요 기능

### 🏫 학교 → 공연장 탐색
- 학교명 검색 → 반경 10km 내 공연장 자동 탐색 (홈 화면에 인라인으로 표시)
- 공연장별 도보·대중교통 이동 시간 제공
- 현재 공연 없는 공연장 음영 구분 표시

### 🎭 공연 대시보드
- 선택한 공연장의 현재 공연·예정 공연 목록 조회
- 공연 상세 정보 (장르, 기간, 관람 연령, 출연진 등)
- **✨ AI 작품 소개**(버튼): 웹 검색 그라운딩으로 정확한 줄거리를 확인하고, 작품의 주제·관람 포인트·교육적 의의·이야깃거리를 학생 눈높이로 소개

### 📚 교육과정 성취기준 연계
- 공연 선택 시 관련 성취기준 자동 매칭 (2022 개정 / 2022 개정 특수 / 2019 누리과정)
- **✨ AI 큐레이션**(버튼): 키워드로 추린 후보를 Gemini가 의미 기반으로 재정렬하고 연계 근거를 제시 (실패 시 키워드 결과 유지)
- 학년군·교과 토글 필터로 원하는 성취기준만 빠르게 탐색

### 🎬 연계 추천 자료
- 공연 주제와 연결된 영화·도서 자동 추천
- **✨ AI 추천 큐레이션**(버튼): 공연과 교육적으로 연관된 영화·도서만 선별·랭킹(근거 포함)하고, 정밀 검색어로 보강해 추천 정확도를 높임

### 🗂 인사이트 바구니
- 공연·성취기준·영화·도서를 바구니에 담아 수업 아이디어 정리
- 이미 담긴 항목은 별도 표시로 중복 담기 방지
- **✨ AI 융합예술 수업 설계**(버튼): 공연을 중심에 두고 영화·도서를 엮어 수업 개요·융합 포인트·학습목표·활동·발문·평가 초안을 생성 → 메모로 저장 (KOPIS 줄거리가 없어도 AI가 웹 검색으로 작품 줄거리를 보완)
- 항목 드래그 앤 드롭 순서 변경
- 메모 작성 기능
- 이미지·PDF 저장 / 클립보드 복사 / URL 공유(단축링크·긴링크 자동 선택) / JSON 파일 저장·불러오기

> 🔋 **AI 모델 폴백 & 배터리 표시**: 무료 티어 한도(429) 도달 시 `gemini-2.5-flash → gemini-2.5-flash-lite` 순으로 자동 전환합니다. 헤더의 배터리 표시로 현재 사용 중인 모델을 확인할 수 있습니다. 모든 AI 기능은 버튼을 눌렀을 때만 호출됩니다.

### 🎭 작품 → 학교 역방향 검색
- 공연 제목으로 검색 → 공연장 위치 기반 인근 학교 탐색
- 학교 클릭 시 해당 학교 기준 공연 대시보드로 바로 이동

### 🔗 인사이트 바구니 공유
- 바구니 내용을 단축링크(`?s=<id>`)로 공유 — Netlify Blobs에 저장
- 긴 base64 링크(`?share=...`)로 자동 폴백 지원

## 데이터 출처

본 서비스는 아래 공개 API를 활용합니다. 각 API의 이용약관을 준수합니다.

| API | 용도 |
|-----|------|
| [KOPIS (공연예술통합전산망)](https://www.kopis.or.kr) | 공연 정보, 공연장 정보 |
| [카카오맵 API](https://developers.kakao.com) | 학교·공연장 위치 검색, 경로 안내 |
| [NAVER Search API](https://developers.naver.com) | 연계 도서 검색 |
| [TMDB](https://www.themoviedb.org) | 연계 영화 검색 |
| [Google Gemini API](https://ai.google.dev) | AI 성취기준 큐레이션·수업 아이디어·의미 보강·웹 검색 그라운딩 (무료 티어) |

> API 키 등 인증 정보는 환경 변수(`.env`)로 관리하며, 이 저장소에 포함되지 않습니다.
> **Gemini 키(`GEMINI_API_KEY`)는 `VITE_` 접두사가 없어 클라이언트 번들에 포함되지 않으며, 서버리스 AI 게이트웨이(`/api/ai/*`)에서만 사용됩니다.**

## 로컬 실행

```bash
# 의존성 설치
npm install

# 환경 변수 설정
cp .env.example .env
# .env 파일에 각 API 키를 입력하세요

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

필요한 환경 변수:

```
VITE_KOPIS_KEY=
VITE_KAKAO_REST_API_KEY=
VITE_KAKAO_JS_API_KEY=
VITE_NAVER_CLIENT_ID=
VITE_NAVER_CLIENT_SECRET=
VITE_TMDB_KEY=
GEMINI_API_KEY=        # 서버 전용 (VITE_ 접두사 금지). Netlify 환경변수에도 등록 필요
```

> 개발 서버(`npm run dev`)는 Vite 플러그인(`server/vite-plugin-ai-dev.mjs`, `server/vite-plugin-share-dev.mjs`)이,
> 운영(Netlify)은 서버리스 함수(`netlify/functions/ai.mjs`, `netlify/functions/share.mjs`)가
> 동일한 AI 핸들러(`netlify/functions/_handlers.mjs`)를 공유해 `/api/ai/*` 및 `/api/share` 엔드포인트를 제공합니다.
> Gemini 키가 없거나 호출이 실패하면 모든 AI 기능은 기존 키워드 기반 결과로 **자동 폴백**합니다.

코드는 오픈소스로 공개되어 있으나, **서비스의 아이디어와 기획을 무단으로 복제하거나 유사 서비스를 제작하는 행위는 지양해 주시기 바랍니다.**

## 면책 조항

기본 성취기준·연계 자료(영화·도서) 추천은 작품명의 핵심 키워드 매칭으로, 기계적 추출 특성상 교육적 의도와 완벽히 일치하지 않을 수 있습니다.
✨ 표시가 있는 AI 기능(작품 소개·큐레이션·융합수업 설계)은 생성형 AI(Google Gemini)가 작성하므로 사실과 다르거나 부정확할 수 있으며, 특히 KOPIS에 줄거리가 없는 작품은 AI가 웹 검색 또는 일반 지식으로 줄거리를 보완하므로 실제 공연과 다를 수 있습니다.
수업 설계 시 반드시 내용을 재확인하고 단순 참고용으로 활용해 주시기 바랍니다.
AI 호출이 불가능한 환경에서는 기존 키워드 기반 결과로 자동 전환됩니다.
