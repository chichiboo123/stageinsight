MODE 1

교사라면 — 우리 학교에서 출발
학교 → 공연장
🏫 학교 검색 → 🎟️ 주변 공연장 → 🎬 공연 선택 → 📚 교육과정

학교 이름만 검색하면 반경 10km 공연장과 현재 공연이 바로 떠요. 공연을 고르면 학년군·교과 성취기준이 자동으로 매칭됩니다.

📸 캡처 자리 🖥️ 학교 검색 → 주변 공연장 목록 화면 실제 앱에서 학교를 검색했을 때 뜨는 공연장 카드 화면을 넣어 주세요
유치원·초·중·고 모두 지원
MODE 2
🎟️
예술가라면 — 작품에서 출발
작품 → 학교
🎟️ 작품 검색 → 📍 공연장 위치 → 🏫 인근 학교 → 🎨 수업 설계

내 작품 제목으로 검색하면 공연장 주변 학교가 보여요. 학교를 고르지 않고 '이 작품으로 바로 수업 설계'도 가능합니다.

📸 캡처 자리 🖥️ 작품 검색 → 인근 학교 탐색 화면 작품으로 검색했을 때 뜨는 공연장 위치·인근 학교 화면을 넣어 주세요
