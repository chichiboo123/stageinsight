공연장 탐색 · 교육과정 매칭 · AI 수업 설계
MODE 1
🏫
교사라면 — 우리 학교에서 출발
학교 → 공연장
🏫 학교 검색 → 🎭 주변 공연장 → 🎬 공연 선택 → 📚 교육과정 연계

학교 이름만 검색하면 반경 10km 공연장과 현재 공연이 바로 떠요. 마음에 드는 공연을 고르면 학년군·교과 성취기준이 자동으로 매칭되어, 오늘 본 공연이 내일의 수업이 됩니다.

유치원·초·중·고 모두 지원
MODE 2
🎭
예술가라면 — 작품에서 출발
작품 → 학교
🎭 작품 검색 → 📍 공연장 위치 → 🏫 인근 학교 → 🎨 수업 설계

내 작품 제목으로 검색하면 공연장 주변 학교가 보여요. 학교를 고르지 않고 ‘이 작품으로 바로 수업 설계’도 가능! 예술가가 직접 교육과정과 연결된 관람 제안을 만들어 학교에 다가갈 수 있어요.
