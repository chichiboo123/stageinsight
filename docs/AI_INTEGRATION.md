# AI 연동 아키텍처 (Google Gemini)

> 목표: **무료 티어 내에서** 토큰을 아껴 쓰면서, 작품 상세 소개·공연 중심 융합예술 수업 설계·
> 영화/도서 추천 큐레이션을 신뢰성 있게 제공한다. 모든 AI는 **버튼 클릭 시에만** 동작한다(남용 방지).

## 1. 구성요소

```
브라우저(클라이언트)                서버(키 보관)                 외부
─────────────────────         ──────────────────────────        ─────────────
src/services/ai.ts   ──POST──▶  /api/ai/<handler>
 · 버튼 트리거 전용                ├─ 개발: server/vite-plugin-ai-dev.mjs
 · 결과 localStorage 캐시          └─ 운영: netlify/functions/ai.mjs
 · aiStatus(AI 아이콘) 보고             └─ netlify/functions/_handlers.mjs ──▶ Gemini API
                                          netlify/functions/_gemini.mjs   (다중 모델 폴백)
```

- **API 키(`GEMINI_API_KEY`)는 서버에만 존재**한다(`VITE_` 접두사 없음 → 번들 미포함).
- 개발/운영이 **동일한 핸들러**(`netlify/functions/_handlers.mjs`)를 공유한다.

## 2. 다중 모델 폴백 (netlify/functions/_gemini.mjs)

`callGeminiJSON()`이 모델 우선순위 체인을 순서대로 시도한다.

| 순위 | 모델 | 비고 |
|------|------|------|
| 1 | `gemini-3.1-flash-lite` | **무료 티어 일일 호출 한도 최대 → 최우선**(정식) |
| 2 | `gemini-3.5-flash` | 신형 Flash(품질) |
| 3 | `gemini-3-flash-preview` | Gemini 3 Flash(프리뷰) |
| 4 | `gemini-2.5-flash` | 검증된 안정 모델(폴백) |
| 5 | `gemini-2.5-flash-lite` | 검증된 안정 경량 모델(최종 폴백) |

> 3.x(특히 `-preview`)는 제공사가 쿼터/이름을 자주 조정·폐기한다
> (`gemini-3.1-flash-lite-preview`는 2026-05-25 종료). 그래서 검증된 2.5 계열을
> 하단 폴백으로 반드시 남겨 두고, 아래 2단계 복구 장치로 이름 변경에 대응한다.

- **429(Rate Limit)·500·503·403·404** → 콘솔 경고 후 다음 모델로 재시도
- **400·401**(형식/인증 오류) → 모델을 바꿔도 실패하므로 즉시 중단
- 모든 모델 실패 시에만 사용자에게 에러 반환
- 반환값 `{ json, model }`의 `model`로 **실제 사용된 모델**을 클라이언트에 전달 → AI 아이콘 색/이름 표시

### 모델명 변경/폐기 대응 (이름이 바뀌어도 멈추지 않게)

하드코딩된 모델명은 제공사 정책으로 언제든 바뀌거나 폐기될 수 있다. 두 단계로 방어한다.

1. **환경변수 오버라이드 `GEMINI_MODELS`** — 쉼표로 구분한 체인을 주면 코드 수정/재배포 없이 교체된다.
   예) `GEMINI_MODELS="gemini-2.5-flash,gemini-2.5-flash-lite"`. 비우면 기본 체인을 쓴다.
2. **런타임 자동 탐색(ListModels)** — 체인의 모델이 `404`(모델 없음)로 실패하면,
   `ListModels` API로 *지금 계정에서 실제로 쓸 수 있는* `generateContent` 텍스트 모델을 1회 탐색해
   대기열에 자동으로 덧붙인다(이미지/임베딩/음성 모델은 제외, flash → flash-lite 순 정렬, 10분 캐시).
   → 하드코딩된 이름이 바뀌어도 살아있는 카탈로그에서 대체 모델을 찾아 복구한다.

## 3. 핸들러 (모두 버튼 트리거)

| 핸들러 | 용도 | 위치 |
|--------|------|------|
| `introduce-performance` | 작품 상세 소개(주제·관람포인트·교육적 의의) — 웹검색 그라운딩 | 공연 상세 |
| `curate-all` | **통합 큐레이션**: 성취기준+영화+도서를 한 번에 — 웹검색 원작 특정 | 대시보드 |
| `lesson-ideas` | 공연 중심 **융합예술 수업** 설계 — 웹검색 줄거리 보완 | 인사이트 바구니 |
| `curriculum-rerank` | (레거시) 성취기준만 단독 재정렬 | — |
| `curate-media` | (레거시) 영화·도서만 단독 큐레이션 | — |

> `curate-all`이 기존 `curriculum-rerank` + `curate-media`를 하나로 통합했다.
> 대시보드 UI는 단일 **"✨ AI 큐레이션"** 버튼으로 `curate-all`만 호출한다.
> 레거시 두 핸들러는 호환을 위해 라우팅 테이블에 남아 있다.

## 4. 통합 큐레이션 흐름 (`curate-all`, 정확도 개선의 핵심)

1. 기본(자동): 성취기준 키워드 매칭 + TMDB·네이버 후보를 즉시 표시(AI 미사용).
2. 사용자가 **"✨ AI 큐레이션"** 1회 클릭.
3. 서버 `curate-all`:
   - **Google 검색 그라운딩으로 작품의 원작/배경을 특정**한다(예: 뮤지컬 `오즈` → `오즈의 마법사`).
   - 성취기준 후보(키워드로 추린 ≤40개)·영화·도서 후보를 **한 번의 호출**로 선별·랭킹(근거 포함).
   - 후보에 원작·핵심 연관작이 없을 수 있으므로 **원작·주제 기반 정밀 검색어**를 제안.
4. 클라이언트가 정밀 검색어로 영화·도서를 보강 검색하고, AI 선별분(💡 근거)을 앞에 배치해 표시.
   원작·배경(`sourceWork`)과 작품 핵심 주제(`themes`)도 함께 노출한다.

> ⚠ 그라운딩(google_search)은 Gemini 2.5에서 `responseSchema`와 동시 사용이 불가하므로,
> `curate-all`은 프롬프트로 JSON을 유도하고 방어적 파서로 결과를 추출한다.

## 5. 토큰 효율 전략

1. **버튼 트리거**: 자동 호출 없음 → 무의미한 API 소비 차단.
2. **통합 호출**: 성취기준·영화·도서를 `curate-all` 한 번으로 처리(2회 → 1회).
3. **후보 압축**: 성취기준 3,373건 전체가 아니라 키워드로 추린 ~40개만 전달.
4. **출력 상한**: 비그라운딩 핸들러는 `responseSchema`, 그라운딩 핸들러는 프롬프트 JSON + `maxOutputTokens` 상한.
5. **결과 캐싱**: `localStorage`(30일) — 동일 입력 재호출 0 토큰.
6. **경량 모델 체인**: 무료 티어 Flash/Flash-Lite.

## 6. AI 모델 표시 (src/components/common/AIStatusBadge.tsx)

- 헤더에 표시. `aiStatus` 스토어 구독.
- **항상 같은 모양의 AI 아이콘(✦ 스파클)**을 쓰고, **색만 모델마다 다르게** 칠해 어떤 모델이 호출됐는지 구분한다(배터리 눈금 아님).
  - 알려진 모델은 고정 색, 그 외(새/개명된 모델)는 모델 ID 해시로 결정적 색을 부여 → 이름이 바뀌어도 안정적으로 색이 매겨진다.
- 모델 이름은 **서버가 돌려준 실제 모델 ID를 그대로 정확히 표시**한다(예: `Gemini 2.5 Flash Lite`).
- 호출 중 → 아이콘 점멸 + "호출 중…" / 성공 → 모델 색·이름 / 실패 → 빨강 "AI 오류".

## 7. 신뢰성(폴백)

- 성취기준: AI 실패 시 키워드 결과 유지
- 영화·도서: AI 실패 시 기본 추천 유지(에러만 안내)
- 작품 소개·수업 설계: 실패 시 모달/영역에 에러 안내(파괴적 영향 없음)
- 재정렬·큐레이션 결과는 **후보 id 화이트리스트**로 검증해 환각 유입 차단

## 8. 배포 체크리스트

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 `GEMINI_API_KEY` 발급(무료).
2. Netlify → Environment variables 에 `GEMINI_API_KEY` 등록(서버 전용).
3. 로컬은 `.env`에 동일 키 추가 후 `npm run dev`.
