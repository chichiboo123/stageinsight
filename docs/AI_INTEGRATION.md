# AI 연동 아키텍처 (Google Gemini)

> 목표: **무료 티어 내에서** 토큰을 아껴 쓰면서, 작품 상세 소개·공연 중심 융합예술 수업 설계·
> 영화/도서 추천 큐레이션을 신뢰성 있게 제공한다. 모든 AI는 **버튼 클릭 시에만** 동작한다(남용 방지).

## 1. 구성요소

```
브라우저(클라이언트)                서버(키 보관)                 외부
─────────────────────         ──────────────────────        ─────────────
src/services/ai.ts   ──POST──▶  /api/ai/<handler>
 · 버튼 트리거 전용                ├─ 개발: server/vite-plugin-ai-dev.mjs
 · 결과 localStorage 캐시          └─ 운영: netlify/functions/ai.mjs
 · aiStatus(배터리) 보고               └─ server/handlers.mjs ──▶ Gemini API
                                          server/gemini.mjs   (다중 모델 폴백)
```

- **API 키(`GEMINI_API_KEY`)는 서버에만 존재**한다(`VITE_` 접두사 없음 → 번들 미포함).
- 개발/운영이 **동일한 핸들러**(`server/handlers.mjs`)를 공유한다.

## 2. 다중 모델 폴백 (server/gemini.mjs)

`callGeminiJSON()`이 모델 우선순위 체인을 순서대로 시도한다.

| 순위 | 모델 | 비고 |
|------|------|------|
| 1 | `gemini-2.5-flash` | 품질 우선 |
| 2 | `gemini-3.1-flash-lite` | 1순위 한도 초과 시 |
| 3 | `gemini-2.5-flash-lite` | 최종 폴백 |

- **429(Rate Limit)·500·503·403·404** → 콘솔 경고 후 다음 모델로 재시도
- **400·401**(형식/인증 오류) → 모델을 바꿔도 실패하므로 즉시 중단
- 모든 모델 실패 시에만 사용자에게 에러 반환
- 반환값 `{ json, model }`의 `model`로 **실제 사용된 모델**을 클라이언트에 전달 → 배터리 표시

## 3. 네 가지 핸들러 (모두 버튼 트리거)

| 핸들러 | 용도 | 위치 |
|--------|------|------|
| `introduce-performance` | 작품 상세 소개(주제·관람포인트·교육적 의의) | 공연 상세 |
| `curriculum-rerank` | 성취기준 의미 기반 큐레이션(근거 포함) | 성취기준 섹션 |
| `curate-media` | 영화·도서 추천 큐레이션 + 정밀 검색어 보강 | 연계 추천 섹션 |
| `lesson-ideas` | 공연 중심 **융합예술 수업** 설계 | 인사이트 바구니 |

## 4. 영화·도서 큐레이션 흐름 (정확도 개선)

1. 기본 추천: TMDB·네이버로 후보를 자동 조회(AI 미사용).
2. 사용자가 **"AI로 추천 정확도 높이기"** 클릭.
3. `curate-media`: 후보 중 공연과 교육적으로 연관된 것만 선별·랭킹(근거 한 줄) +
   더 적합한 작품을 위한 **정밀 검색어** 제안.
4. 클라이언트가 정밀 검색어로 보강 검색 → AI 선별분(💡 근거)을 앞에 배치해 표시.

## 5. 토큰 효율 전략

1. **버튼 트리거**: 자동 호출 없음 → 무의미한 API 소비 차단.
2. **후보 압축**: 성취기준 3,373건 전체가 아니라 키워드로 추린 ~40개만 전달.
3. **구조화 출력(responseSchema)** + `maxOutputTokens` 상한.
4. **결과 캐싱**: `localStorage`(30일) — 동일 입력 재호출 0 토큰.
5. **경량 모델 체인**: 무료 티어 Flash/Flash-Lite.

## 6. 배터리 표시 (src/components/common/AIStatusBadge.tsx)

- 헤더에 표시. `aiStatus` 스토어 구독.
- 호출 중 → 점멸 / 성공 → 사용 모델명 + 배터리 눈금(1순위=3칸 초록, 2순위=2칸 노랑, 3순위=1칸 주황) / 실패 → 빨강.

## 7. 신뢰성(폴백)

- 성취기준: AI 실패 시 키워드 결과 유지
- 영화·도서: AI 실패 시 기본 추천 유지(에러만 안내)
- 작품 소개·수업 설계: 실패 시 모달/영역에 에러 안내(파괴적 영향 없음)
- 재정렬·큐레이션 결과는 **후보 id 화이트리스트**로 검증해 환각 유입 차단

## 8. 배포 체크리스트

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 `GEMINI_API_KEY` 발급(무료).
2. Netlify → Environment variables 에 `GEMINI_API_KEY` 등록(서버 전용).
3. 로컬은 `.env`에 동일 키 추가 후 `npm run dev`.
